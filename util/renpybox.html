# 使用RenpyBox进行翻译

现在已经是属于AI新时代了，末法时代结束了。如今人人都可以使用AI进行汉化，只是时间快慢而已。RenpyBox 是集成了 Ren'Py 相关模块制作的集成工具，包含

解包、反编译、提取翻译、补新翻译、本地词库、禁翻库、使用LLM AI进行翻译、自动填充字体、自动增加中文选项、封包等功能，因为本人只针对 Renpy 游戏引擎，所以其他游戏引擎一律不进行优化，请知晓。

下载地址：https://github.com/Dclef/renpybox/releases

说明

v0.9.0 起提供全新 Windows 桌面界面（推荐），旧 Python / Qt5 版与源码继续保留。本教程基于桌面版 v0.9.1 编写。

# 下载与安装

到 GitHub Releases (opens new window) 下载对应文件：

文件 用途
RenpyBox-NewUI-x.x-x64.exe Windows 安装程序，推荐使用
RenpyBox-NewUI-x.x-x64.zip 免安装包，完整解压后运行其中的程序
RenpyBox_vx.x.zip 保留旧界面的 Python 兼容包，供老版本用户更新

桌面版已附带运行环境，不需要额外安装 Python。应用配置保存在 %APPDATA%\RenpyBox-newUI，与 Python 版相互独立、不会互相覆盖。

打开后是主界面，左侧是导航，右侧默认是「翻译任务」页：

# 界面总览

左侧是主导航：

  • 翻译任务：执行翻译、查看进度、继续任务、写回译文
  • Agent 助手：内置 AI 助手，可检查项目、扫描脚本问题
  • 项目设置：绑定 Ren'Py 工程，设置语言与输入 / 输出目录
  • 接口管理：添加、测试翻译接口
  • Ren'Py 工具箱：27 个工具，按工作流分组
  • 角色 / 世界观工作台：维护角色卡、世界观与提示词
  • 基础设置：并发、RPM、自动保存等常规项
  • 专家设置：提示词、资产分析、结果检查等高级行为
  • 翻译提示：预览与编辑翻译提示词

底部左下角两个按钮分别是切换主题（浅色 / 深色）和应用设置；界面语言在「基础设置 → 应用界面语言」中切换，重启后生效。

# 基本配置

# 第一步：配置翻译接口

点开「接口管理」，在这里添加并测试翻译接口：

  • 点右上角「+ 新增接口」添加接口，免费 Google / Bing 翻译无需申请 Key（需要能访问对应服务的网络）；付费接口按平台要求填写 Key
  • 接口列表按「本地模型 / 传统机翻 / 在线大模型 / 自定义接口」分组，顶部显示当前启用的「主翻译接口」
  • 添加后建议先点接口卡片上的测试按钮，确认能正常返回再用于翻译
  • 翻译质量取决于所选接口，可按需选择

# 第二步：项目设置

返回「项目设置」，绑定 Ren'Py 工程（选择包含 game/ 的项目根目录），然后设置原文语言和译文语言：

  • 原文语言 / 译文语言：请按游戏的语言做判断
  • 输入文件夹：翻译读取目录，一般是 game/tl/<语言>
  • 输出文件夹：译文写出目录
  • 「任务完成时打开输出文件夹」：任务结束后自动打开输出目录
  • 「使用整体输出中文」开启后，译文语言为中文时会使用繁体字形输出

输入和输出文件夹最好先去手动设置一下，虽然本项目做了自动化设置，但为了防止万一还是先确认一遍。

# 第三步：基础设置

「基础设置」里的并发任务阈值和每分钟任务数（RPM）可以自行调整，用默认也无所谓。如果外部接口超时 / 限速，就在这里调小并发，而不是在「接口管理」里改。

# 第四步（可选）：专家设置与翻译提示

一般不需要动。需要更精细控制时：

  • 专家设置：控制提示词、资产分析、结果检查等高级行为；开启「专家模式」会显示更多日志与高级选项，重启后生效
  • 翻译提示：可预览和编辑提示词
    • 基础模式：通用 适合大多数游戏；逐步推理（COT）让模型在翻译前显式分析上下文，对长对话更稳；深度思考（THINK）适合多语种 / 文学性强的段落；本地模型 简化提示以适配本地小模型
    • 写作风格：文学化 提高文笔、古典文风 走古白话、成人内容（R18）放宽对 NSFW 词句的润色；自定义可直接改提示词
    • 修改后会保存并在翻译时生效；若发现译文风格不对（太白话 / 太文绉绉 / 被过度审查），就来这里切换

至此基本配置完成，可以开始翻译。

# 一键翻译

打开「Ren'Py 工具箱」，找到一键翻译（推荐流程第 1 步）：

# 准备项目

输入游戏根目录（注意是包含 game/ 的目录），选择原文 / 译文语言，确认抽取模式后点击「开始准备」：

  • 抽取模式：
    • 自动：检测到已有译文时用增量，否则全量
    • 增量抽取：保留已有译文，只重译变化部分，推荐
    • 全量抽取：备份后重新生成，慎用
  • 先执行官方抽取：自动寻找游戏 exe 执行官方翻译抽取；官方抽取 EXE 路径留空则自动识别（未勾选时不执行官方抽取）
  • 检测到 RPA 会自动解包并补齐反编译，不需要先手动操作
  • 准备阶段不会自动调用收费翻译接口，可以放心点

显示提取完成后，可以到「翻译任务」页查看详细进度，也可以继续下一步配置词表。

# 术语表

点「下一步」进入术语表。这里先点击「扫描角色名」自动提取角色名：

  • 术语表保存后，翻译时会优先采用这些译法
  • 「导入 Excel / 导出 Excel」可批量维护；「LLM 翻译 / 快速翻译」可批量填充后人工校对
  • 「统计命中」查看词条在译文中的命中情况

注意

这里会有很多选项。如果要添加术语库，最好的方式就是自己手动去翻译，因为 LLM 或其他方式都可能翻译不到位；「自动分类」是根据 NER 模型识别分类的，有一定概率识别不到。配置好一定要点「保存到项目」！一定要保存！

# 禁翻表

术语表之后是禁翻表，管理不需要翻译的变量、代码和占位符：

# 开始翻译

配置好词表后回到「翻译任务」页，确认当前接口和输入 / 输出目录，点击「开始翻译」：

# 翻译任务页

翻译过程中任务页会实时显示：

  • 进度：已翻译条数 / 总条数、剩余时间、剩余批次
  • Token 统计：输入 / 输出 Token、线程池占用
  • 任务平均吞吐与有效翻译速度（条/秒、Token/s）
  • 近期翻译流水：逐条显示原文与译文，完整记录保留在翻译缓存里

底部操作按钮：

  • 开始翻译 / 停止：启动或中断当前任务
  • 继续任务：中断后从断点继续，已有译文不会重译
  • 写入译文文件：把缓存中的译文写回到输出文件夹（TL 目录）
  • 估算 Token：不发起翻译，先估算本次任务消耗
  • 重翻失败项：只重试失败的条目
  • 定时器：定时执行翻译任务

提示

翻译缓存位于当前输出目录下的 cache 子目录。任务中断后可以直接「继续任务」，也可以先导出已完成部分。

# 两个「写回」按钮的区别

  • 「写入译文文件」（任务页底部）：把翻译缓存写回当前项目的输出文件夹（game/tl/<译文语言>/）
  • 「应用翻译到游戏」（工具箱）：把 TL 目录的内容应用到游戏根目录，让游戏运行时能读到

正常流程：先在任务页翻译 → 「写入译文文件」落盘到 TL → 再用「应用翻译到游戏」把 TL 拷到游戏根目录。

# 校对与修正

翻译完成后，使用「检查与润色」（或任务页右上角「打开平行校对台」）查看质量报告、校对或润色译文：

校对台支持原文 / 译文左右对照、筛选、相似度与占位符检查，也可直接定位到译文所在行并打开文件：

如果想离线批量改：打开工具箱的「批量修正」，生成相应的 Excel，编辑后用「注入修正」回写。

注意

校对结果保存在翻译缓存里，不会自动改写游戏文件。确认后用任务页的「写入译文文件」或工具箱的「应用翻译到游戏」写回。

# 工具箱其他工具

工具箱共 27 项，按工作流分四组。

# 推荐流程

工具 作用
一键翻译 选择游戏目录，自动完成抽取和翻译
检查与润色 查看质量报告、校对或润色译文并导出
应用翻译到游戏 将翻译结果写入游戏的 TL 目录
字体注入 注入预置字体包及对应的界面适配脚本
添加语言入口 向游戏添加语言切换功能
设置默认语言 设置游戏启动时的默认语言
术语表 管理当前项目专有名词对照，统一译法
禁翻表 管理不需要翻译的变量和代码
继续翻译 检测到上次未完成的翻译任务时恢复

# 翻译方式

工具 作用
RPY 抽取设置 分类管理源码和 TL 的内置抽取、自定义正则及使用方案
翻译抽取到 TL 使用官方抽取、运行时抽取等高级抽取方式
直接翻译 RPY 直接翻译 tl/*.rpy 文件
HOOK 翻译 运行游戏并抽取文本后直接翻译
源码翻译 直接翻译 game/*.rpy 源码
补全翻译 扫描漏提文本并生成补全脚本
文本提取 JSON 导出 JSON 供人工翻译，再导入并应用到 TL

# 资源与词表

称呼桥接（处理称呼和变量组合文本）、终极结构导出（导出 Excel 和结构化翻译脚本）、批量修正（通过 Excel 批量修正质检报告中的译文）、姓名提取（扫描脚本与 JSON，生成角色名清单）。

# 工程与修复

解包 / 打包（RPA 解包、RPYC 反编译）、错误修复（扫描并修复翻译目录中生成的 .rpy 错误）、更新翻译复用（按原文将旧译文填入新版本的空条目）、代码格式化、安卓打包、网页 / AI 翻译向导（把 TL 目录变成 TXT，交给 AI 或网页翻译，再一键回填）、游戏模组注入。

提示

带「需先选择游戏目录」提示的工具依赖当前项目，先在「项目设置」或「一键翻译」里选好目录；其他工具可在各自页面选择输入文件或目录。

# 收尾三步

翻译完成后通常还需要：

  1. 应用翻译到游戏：将翻译结果写入游戏的 TL 目录
  2. 设置默认语言：让游戏启动时默认中文
  3. 添加语言入口：如果游戏原本没有语言切换菜单

如果界面出现方块字，用字体注入补上字体（一键翻译过程中已经自动实现，这里只是额外功能）：

# 完整流程速览

把上面的零散步骤串成一条最短路径：

  1. 配置：接口管理 → 项目设置 →（可选）基础设置 / 专家设置 / 翻译提示
  2. 抽取：工具箱 → 一键翻译 → 输入游戏根目录 → 选「增量抽取」→ 开始准备
  3. 词表：术语表 → 扫描角色名 → 手动补关键译法 → 保存到项目；随后维护禁翻表
  4. 翻译：翻译任务页 → 开始翻译（断点用「继续任务」）
  5. 写回：翻译任务页 → 写入译文文件
  6. 校对：检查与润色（或平行校对台）→ 批量修正（可选）
  7. 收尾：应用翻译到游戏 → 设置默认语言 →（如需要）添加语言入口 / 字体注入
  8. 更新游戏版本：工具箱 → 继续翻译 / 更新翻译复用，按原文把旧译文灌进新版本的空条目

「Agent 助手」内置 AI Agent，可以检查当前项目、扫描脚本问题、查询翻译状态，并在你确认后执行 RPA 解包和一键翻译。适合不想逐步点工具箱时直接对话操作：

# 角色 / 世界观工作台

工作台用于维护项目级的世界观、角色卡，可直接预览和编辑翻译提示词。角色资料支持导入导出、批量应用草稿：

# 应用设置与更新

在左下角进入「应用设置」，可检查更新、查看更新日志、导出运行日志：

  • 桌面版更新下载完整安装包，含大小与 SHA-256 校验，损坏文件不会进入安装流程
  • 安装前会检查是否有任务在运行，避免中断翻译
  • 免安装用户也可手动下载新版 ZIP 覆盖解压

# 从旧版迁移

  • Python 版与桌面版的配置目录相互独立，升级桌面版不会影响旧版配置
  • 需要沿用旧接口时，在桌面版「接口管理」点击「新增接口 → 从旧版导入」，选择 Python 版程序目录下的 config.json 即可，密钥会自动沿用
  • 旧译文可以通过工具箱「更新翻译复用」按原文填入新版本的空条目
  • 迁移不会自动替换原 Python 应用，旧版可继续使用

# 常见问题

  • 翻译缓存找不到：缓存在当前输出目录下的 cache 子目录，不是固定的 output/cache
  • 接口超时 / 限速：在「基础设置」调小并发任务阈值和 RPM，不要在「接口管理」里改
  • 打开游戏报错或一片空白：先用「错误修复」扫描修复 .rpy 语法、缩进、引号和重复条目；再用「补全翻译」补漏
  • 界面出现方块字：用「字体注入」补字体，或在 FAQ 里看手动换字体的方法
  • 游戏打开不是中文：用「设置默认语言」，或在 screens.rpy 里加 define config.language = "chinese"
  • 导出文本不全：先用「RPY 抽取设置」调整抽取规则，或改用「源码翻译」直接处理 game/*.rpy
  • 看日志：桌面版在「应用设置 → 运行日志」导出；Python 版在程序目录下的 log
